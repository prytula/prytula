## Oleksandr Prytula

Frontend engineer, six years commercial — the last two and a half in payments.
I build the interfaces where money actually moves, and increasingly the services behind them.

**Day job.** Payment platform: deposits, withdrawals and payout detail forms rendered
dynamically from backend-driven schemas across 8+ crypto and fiat methods. Transaction
views over thousands of records, a server-rendered admin panel, public docs built from
Markdown. One of four frontend engineers and the only one working across every project,
which mostly means being handed unfamiliar code and expected to ship.

**Alongside that**, commercial work delivered end to end for business clients — Telegram
products with payment processing (one in production and maintained for two years), CRM
integrations, a React frontend against a Rust backend over gRPC. All of it deployed and
kept alive on infrastructure I run myself.

**AI as a build tool, not a buzzword.** A year and a half authoring reusable agent skills
and workflows, including a plan → execute → review → commit pipeline that took site
delivery from roughly three days to two or three hours across about fifty builds. Review
gate stayed human: a defect log, a fixed 30–40 minute verification pass per build. I also
cost-model hosted APIs against self-hosted open-source models before committing to a stack.
